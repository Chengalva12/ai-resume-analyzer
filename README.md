# AI Resume Analyzer 🚀

An AI-powered Resume Analyzer that evaluates ATS score, detects missing skills, and provides smart resume improvement suggestions based on job descriptions.

##  Features

- Upload PDF Resume
- ATS Score Calculation
- Skill Matching
- Missing Skill Detection
- Resume Improvement Suggestions
- FastAPI Backend
- React + Vite Frontend
- Fully Deployed Online

## Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- FastAPI
- Python
- PyMuPDF

### Deployment
- Vercel (Frontend)
- Render (Backend)

##  Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
